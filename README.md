# MARATHON // World Guide

An interactive, single-file fan guide to the universe of **Marathon** (Bungie, 2026) - the fall of the Tau Ceti IV colony, Runners and shells, the six factions, AI rampancy, the full arsenal, the classic 1990s trilogy and its Halo legacy.

![Marathon key art](https://images.contentstack.io/v3/assets/blt15f7b5c0d43ed112/blt4579a520aea7477a/699c18b848bd410008f09c63/Hero_Video_Fallback_Image.png?width=1200&quality=80)

## What's inside

- **Four languages** - EN / ES / DE / RU, switchable in the top bar, full content parity.
- **14 briefing sections + a complete arsenal manifest** - from "start here" for newcomers to deep cuts for trilogy veterans.
- **Honest sourcing** - every lore claim is tagged `canon` / `datamine` / `theory`, and contested points are flagged as open questions instead of being smoothed over.
- **One self-contained HTML file** - no build step, no frameworks, no tracking. Interactive CRT terminals, hover glossary tooltips, original SVG pictograms.

## Deploying on GitHub Pages

1. Push this folder to a public repository.
2. Settings -> Pages -> Deploy from a branch -> `main` / `(root)`.
3. The guide is served at `https://<username>.github.io/<repo>/`. `404.html` ships its own easter egg.
4. Optional: uncomment and fill the `canonical` link in the `<head>` of `index.html` once the URL is known.

Text and inline SVG work fully offline; official artwork is hotlinked from Bungie's public CDN and requires a network connection.

## Versioning

Current: **v4.1** (July 2026 - Season 2 "Nightfall" era). Fact-checked against community primary sources: marathonwiki.com, marathon.bungie.org, tauceti.gg, marathondb.gg, breacher.net, halopedia.org and contemporary press coverage.
